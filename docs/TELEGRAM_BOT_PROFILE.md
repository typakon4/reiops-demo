# Telegram Bot Profile

## Bot name

ReiOps

## Short description

Business-ready AI agents with approvals, audit logs, and managed support.

## About

Make AI agents safe for businesses.

## Long description

ReiOps is a managed operations layer for AI agents. This demo shows how a vetted AI workflow runs in a secure sandbox, streams an execution trace, blocks risky actions by policy, and asks a human to approve before opening a PR.
