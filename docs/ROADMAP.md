# Roadmap

ReiOps is an early prototype. This roadmap describes the product direction, not current production guarantees.

## Near Term

- Improve the GitHub Issue Fixer demo flow
- Add clearer policy explanations and audit history
- Polish Telegram approval UX
- Add more realistic workflow templates
- Add screenshot/video assets for investor and customer demos

## Design Partner Version

- Real GitHub integration for controlled test repositories
- Workspace/team accounts
- Scoped repository permissions
- Persistent audit logs
- Configurable policy gates
- Approval roles
- Basic billing/cost tracking

## Managed Marketplace

- Curated workflow catalog
- Workflow install/setup flow
- Workflow health checks
- Managed support playbooks
- Versioned workflow templates
- Customer-specific configuration

## Enterprise Control Plane

- SSO and role-based access control
- Policy engine for risky actions
- Sandbox profiles and tool permissions
- Audit export
- SLA monitoring
- Integration with ticketing/ITSM systems
- Deployment options for customer-controlled infrastructure

## Long-term

- Trusted distribution layer for vetted agents
- Marketplace for builders to publish approved workflows
- Governance layer for agent tool access, spending, and approvals
- Standardized audit records for agentic work
